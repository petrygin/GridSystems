## How to use prototype

Download `connect-flow-prototype-v3.html` and open in browser.
Or enable GitHub Pages and open:
`https://zloe4mo.github.io/GridSystems/DSG_Demo2/connect-flow-prototype-v3.html`

### Key interactions
- Click component on SLD → Info Panel opens
- Hover → blue highlight + ports appear → drag from port to connect
- Right-click → context menu (connect to..., disconnect, delete, bind)
- Right-click Map → Add structure (Pole/Vault/Pad)
- Shift+click → multi-select → Enter to connect
- Cmd+Z / Ctrl+Z → undo (50 steps)
