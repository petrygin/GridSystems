Принцип — 3 канала сигнала

Тело иконки
Зависит от текущего «Highlight by»: Components → цвет = тип; Zones → цвет = зона; None → IEC ч/б. Тип компонента известен всегда — это атрибут модели, цвет — режим отображения.
Halo вокруг иконки
Первичное интерактивное состояние: Hover, Selected, Snap-target (Map), In-flight. Один цвет за раз. Работает поверх ЛЮБОГО highlight-режима.
Бейдж + opacity
Validation — стопка бейджей (? / Unlink / ! / counter). DRAFT/Pending = ?. Out-of-scope = opacity + grayscale. Read-only = только cursor: not-allowed.

Read-only
Approved / frozen. Иконка сохраняет нативный вид. При hover курсор показывает not-allowed, клик игнорируется.

Иконка вне текущего scope. Ghost-правило: десатурирована + opacity, без hover/click. Единое правило для Map и SLD, для иконок и линий.

6.2. Connection point — состояния и визуальный язык

Принцип: outline / fill различают connectivity-статус, halo — интерактивный статус, цвет — snap-validity. Start-point и end-point визуально не различаются.
  • Outline (hollow) = терминал свободен (IEC-конвенция).
  • Filled (solid) = терминал занят (junction-dot правило).
  • Halo = hover ИЛИ snap-target highlight.
  • Цвет: default · success · warning · error.
Default
Success
Warning
Error
Outline · unconnected · idle
Outline + halo · hover or snap-active
Filled · connected · idle
Filled + halo · hover on connected
Геометрия (Figma 2857:43205, 4px-сетка):
  • Connection dot: diameter 12px (r=6), stroke 1.5px для outline.
  • Halo: diameter 20px (r=10), расширение +4px наружу.
  • Drop-shadow: shadow-xs = 0 1px 2px #0000000d.
Токены:
  • Default: stroke general/border · fill general/primary · halo general/border
  • Success / Warning / Error: GS-surface/status/{success|warning|destructive}/{default|subtle}

На SLD multi-conductor неприменим. На Map — LOD-зависимая отрисовка: на низком зуме один объект + метка, на высоком — fan-out.
